= EventBus — Channel bounded in-process
include::partial$_attributes.adoc[]
:icons: font

Barramento in-process com handlers assíncronos, priorização e resolução por hierarquia de tipos. `Channel<object> bounded 1000 by default`, `FullMode.Wait` backpressure, workers paralelos sem `Task.Delay` busy-loop, drenagem `Writer.Complete + WhenAll` no `StopAsync`.

== Registro via DI

[source,csharp]
----
services.AddEventBus(); // 4 workers, capacity 1000, FullMode.Wait, DrainOnStop true

services.AddEventBus(o =>
{
    o.WorkerCount = 4;
    o.Capacity = 1000;
    o.FullMode = BoundedChannelFullMode.Wait; // Wait, DropNewest, DropOldest, DropWrite
    o.DrainOnStop = true;
    o.AutoRegisterHandlers = true; // registra IEventHandler<T> + [EventListener] via Walk
});

services.AddDependencyWalk("MeuProjeto", config, typeof(Program).Assembly); // descobre handlers
----

== Handlers por Atributo [EventListener]

[source,csharp]
----
public class UserCreatedHandler
{
    [EventListener(Priority = 10)]
    public async Task OnUserCreated(UserCreatedEvent evt)
    {
        // lógica
    }

    [EventListener] // Priority 0
    public void OnUserCreatedSync(UserCreatedEvent evt) { }
}
----

Método deve ter 1 parâmetro (tipo do evento), retorna `void` ou `Task`.

== Handlers Tipados IEventHandler<T>

[source,csharp]
----
public class UserCreatedEventHandler : IEventHandler<UserCreatedEvent>
{
    public async Task Handle(UserCreatedEvent evt, CancellationToken ct = default)
    {
        // processa
    }
}
// auto-descoberta + Transient no DI via Walk
----

== Subscrição Manual

[source,csharp]
----
var bus = provider.GetRequiredService<EventBus>();
bus.Subscribe<UserCreatedEvent>(async evt => await DoSomething(evt.UserId), priority: 5);
bus.Subscribe(new UserCreatedEventHandler(), priority: 10);

// herda: handler de IEvent recebe UserCreatedEvent se UserCreatedEvent : IEvent
----

== Publicação

[source,csharp]
----
bus.Publish(new UserCreatedEvent { UserId = 123 }); // TryWrite fire-and-forget, warn se cheio
await bus.PublishAsync(new UserCreatedEvent { UserId = 123 }, ct); // WriteAsync backpressure com ct

// tipado
await bus.PublishAsync<UserCreatedEvent>(new UserCreatedEvent { UserId = 123 });
----

----

----

== Prioridade

`Priority` maior executa primeiro; mesmo nível executa em paralelo `Task.WhenAll`.

[source,csharp]
----
[EventListener(Priority = 100)] public void Critical(MyEvent e) { } // primeiro
[EventListener(Priority = 0)]   public void Normal(MyEvent e) { }  // depois
[EventListener(Priority = -10)] public void Low(MyEvent e) { }    // por último
----

== Resiliência & Testes

* `Channel` bounded evita OOM — `FullMode.Wait` provoca backpressure `PublishAsync` em vez de loss.
* `StopAsync` drena fila — `Writer.TryComplete()` + `await WhenAll(workers)` garante 0 perda.
* Testes: `EventBusChannelTests` bursts `10k Publish` sem loss + `Capacity=2` backpressure + `StopAsync` drena.
