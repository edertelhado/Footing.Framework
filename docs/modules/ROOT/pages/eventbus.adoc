= EventBus
include::partial$_attributes.adoc[]
:icons: font

Barramento in-process com `Channel<T>` bounded, workers paralelos e priorização. Para desacoplar módulos sem broker externo.

== Conceito

*   `Publish` enfileira em `Channel` bounded (`FullMode.Wait` por padrão) — backpressure em `PublishAsync`
*   Workers drenam via `ReadAllAsync` sem `Task.Delay` — `StopAsync` faz `Writer.Complete + WhenAll`
*   Handlers resolvem por hierarquia — handler de `IEvent` recebe `UserCreatedEvent : IEvent`
*   Prioridade maior executa primeiro, mesmo nível em paralelo via `Task.WhenAll`

== Registro

[source,csharp]
----
services.AddEventBus(); // 4 workers, capacity 1000, FullMode.Wait, DrainOnStop true

services.AddEventBus(o => {
  o.WorkerCount = 4;
  o.Capacity = 1000;
  o.FullMode = BoundedChannelFullMode.Wait; // Wait | DropNewest | DropOldest | DropWrite
  o.DrainOnStop = true;
  o.AutoRegisterHandlers = true;
});
services.AddDependencyWalk("MeuProjeto", config, typeof(Program).Assembly);
----

== Handlers

[source,csharp]
----
// Atributo — qualquer método público com 1 parâmetro
public class UserCreatedHandler {
  [EventListener(Priority = 10)]
  public async Task OnUserCreated(UserCreatedEvent evt) { /* ... */ }

  [EventListener] // Priority 0
  public void OnUserCreatedSync(UserCreatedEvent evt) { }
}

// Tipado — auto-descoberta via Walk
public class UserCreatedEventHandler : IEventHandler<UserCreatedEvent> {
  public async Task Handle(UserCreatedEvent evt, CancellationToken ct = default) { /* ... */ }
}

// Manual
var bus = provider.GetRequiredService<EventBus>();
bus.Subscribe<UserCreatedEvent>(async evt => await DoSomething(evt.UserId), priority: 5);
bus.Subscribe(new UserCreatedEventHandler(), priority: 10);
----

Método deve ter 1 parâmetro (tipo do evento), retorna `void` ou `Task`.

== Publicação

[source,csharp]
----
bus.Publish(new UserCreatedEvent { UserId = 123 }); // TryWrite fire-and-forget
await bus.PublishAsync(new UserCreatedEvent { UserId = 123 }, ct); // WriteAsync com backpressure
----

[source,mermaid]
----
sequenceDiagram
  participant P as Publisher
  participant C as Channel
  participant W as Workers
  participant H as Handlers
  P->>C: Publish WriteAsync
  C->>W: ReadAllAsync
  W->>H: Task.WhenAll priority group
  H-->>W: Task
  W-->>C: drain on StopAsync
----

== Prioridade

[source,csharp]
----
[EventListener(Priority = 100)] public void Critical(MyEvent e) { } // primeiro
[EventListener(Priority = 0)]   public void Normal(MyEvent e) { }  // depois
[EventListener(Priority = -10)] public void Low(MyEvent e) { }    // por último
----

== Resiliência

*   `Channel` bounded evita OOM — `FullMode.Wait` aplica backpressure em `PublishAsync`
*   `StopAsync` drena fila — garante 0 perda no shutdown
