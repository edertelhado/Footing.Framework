Um conjunto de componentes de infraestrutura .NET independentes, que você pode usar separadamente, sem ORM obrigatório, sem broker obrigatório e sem precisar adotar uma arquitetura fechada.

Use apenas o que precisar. O Footing não impõe domínio, persistência, mensageria ou arquitetura. Os componentes são independentes e extensíveis por interfaces/SPI. Se não registrar `IOutboxStore`, não existe outbox. Se não registrar `IMigrationJournal`, usa `DefaultMigrationJournal` SQL-97.

[source,csharp]
----
// Program.cs — 20 segundos para entender
builder.Services.AddMigrations(o => o.EmbeddedAssembly = typeof(Program).Assembly);
var tpl = SqlTemplate.Parse("SELECT * FROM users {WHERE} {IF:Name} AND name=@Name {END} {ENDWHERE}");
var r = tpl.Render(new { Name = "eder" });
await conn.QueryAsync<User>(r.Sql, r.Parameters);
----

== O que resolve

*   **Desacoplamento sem broker** — `EventBus` in-process `Channel<T>` bounded
*   **Queries dinâmicas sem ORM** — `SqlTemplate` 11 tags + Dapper agnóstico
*   **Migrations embarcadas** — `AddMigrations(Assembly)` com `*.sql` como `EmbeddedResource`, SQL-97
*   **Multi-banco** — PostgreSQL, Firebird, MySQL, SQLite — mesmo binário, `IDbConnectionFactory` agnóstico
*   **Resiliência opcional** — `IIdempotencyStore`/`IOutboxStore` via `TryAdd`
