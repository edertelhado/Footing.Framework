= Visão Geral

:icons: font

Sapata .NET não-invasiva para apps que precisam de EventBus, Data Layer dinâmico e Migrations SQL puras sem carregar um framework pesado. Inspirado em Spring Boot auto-configuration + Rust features + PostgreSQL docs (SQL puro).

Filosofia: **TryAdd / SPI**. O core não obriga nada. Se não registrar `IOutboxStore`, não existe outbox. Se não registrar `IMigrationJournal`, usa `DefaultMigrationJournal` SQL-97. Quem precisa pluga fora do `src/`.

== O que resolve

*   **Desacoplamento sem broker** — `EventBus` in-process `Channel<T>` bounded
*   **Queries dinâmicas sem ORM** — `SqlTemplate` 11 tags + Dapper agnóstico
*   **Migrations embarcadas** — `AddMigrations(Assembly)` com `*.sql` como `EmbeddedResource`, SQL-97
*   **Legado Firebird/dbf + PostgreSQL** — mesmo binário, `IDbConnectionFactory` agnóstico
*   **Resiliência opcional** — `IIdempotencyStore`/`IOutboxStore` via `TryAdd`
