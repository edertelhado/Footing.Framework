== Arquitetura

[source,mermaid]
----
flowchart LR
  Controller --> Service["Service"]
  Service --> Repo["Repository"]
  Repo --> Dapper
  Dapper --> Factory["IDbConnectionFactory"]
  Factory --> DB[("PG Firebird dbf via SPI")]
  Service --> EB["EventBus Channel bounded"]
  EB --> Handler["IEventHandler Priority"]
  Service --> Outbox["OutboxProcessor poll 2s"]
  Outbox --> Store["IOutboxStore"]
  Service --> Batch["SqlBatch chunked"]
  Migrations["MigrationRunner YN"] --> Factory
  OTel["ActivitySource"] -.-> EB & Dapper & Batch
  Health["Health Checks"] -.-> Factory & EB
----

*Princípios:* agnóstico DB (GLOBAL_RULES 59L), SPI `IOutboxStore/IIdempotencyStore` 0 deps, `<3.5K LOC`, `11 GeneratedRegex` source-gen AOT, fail-fast estrutura vs fail-safe dados.
