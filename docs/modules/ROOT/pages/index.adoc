Infraestrutura pequena e pragmática para aplicações .NET que precisam de EventBus, SQL dinâmico, migrations e componentes de infraestrutura sem adotar um framework inteiro.

Filosofia: **TryAdd / SPI**. O core não obriga nada. Se não registrar `IOutboxStore`, não existe outbox. Se não registrar `IMigrationJournal`, usa `DefaultMigrationJournal` SQL-97.

== O que resolve

*   **Desacoplamento sem broker** — `EventBus` in-process `Channel<T>` bounded
*   **Queries dinâmicas sem ORM** — `SqlTemplate` 11 tags + Dapper agnóstico
*   **Migrations embarcadas** — `AddMigrations(Assembly)` com `*.sql` como `EmbeddedResource`, SQL-97
*   **Multi-banco** — PostgreSQL, Firebird, MySQL, SQLite — mesmo binário, `IDbConnectionFactory` agnóstico
*   **Resiliência opcional** — `IIdempotencyStore`/`IOutboxStore` via `TryAdd`
