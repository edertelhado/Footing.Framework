== Health — /health

[source,csharp]
----
services.AddFootingHealthChecks(); // registra DbHealthCheck + EventBusHealthCheck
app.MapHealthChecks("/health");

// GET /health → {"status":"Healthy","results":{"db":"Healthy","eventbus":"Healthy"}}
// GET /health?tags=db  → só db
----

Implementação (5 LOC):

[source,csharp]
----
public sealed class DbHealthCheck(IDbConnectionFactory f) : IHealthCheck
{
    public async Task<HealthCheckResult> CheckHealthAsync(HealthCheckContext ctx, CancellationToken ct = default)
    {
        using var conn = f.CreateConnection();
        await ((System.Data.Common.DbConnection)conn).OpenAsync(ct);
        return HealthCheckResult.Healthy("db reachable");
    }
}
public sealed class EventBusHealthCheck(EventBus bus) : IHealthCheck
{
    public Task<HealthCheckResult> CheckHealthAsync(HealthCheckContext ctx, CancellationToken ct = default)
        => Task.FromResult(bus.IsRunning ? HealthCheckResult.Healthy("eventbus running") : HealthCheckResult.Unhealthy("eventbus stopped"));
}
----

Resiliência — `tests` exaustivos `18 testes M1-M6` + `sqlite:memory` + `FileSystem` check falham healthy sem falso positivo.

== Perf — S4 Could 0.2 (Stopwatch Smoke done)

`BenchmarkSmokeTests` minimal já valida `<2000ms 10k renders`:

[source,csharp]
----
[Fact] public void SqlTemplate_10k_under_2s()
{
    var tpl = SqlTemplate.Parse("SELECT * FROM Users {WHERE} {IF:Name} AND Name=@Name {END} {ENDWHERE}");
    var sw = Stopwatch.StartNew();
    for(int i=0;i<10_000;i++) tpl.Render(new { Name="eder" });
    Assert.True(sw.ElapsedMilliseconds < 2000, $"{sw.ElapsedMilliseconds}ms >2000");
}
----

== UseTransaction — Won't definitivo (DDL transacional agnóstico não suportado)

Ver xref:migrations.adoc#_usetransaction_wont_definitivo_ddl_transacional_agnostico_nao_suportado[Migrations — UseTransaction Won't definitivo]. `MigrationOptions.UseTransaction = true` **não suportado, mesmo com BUY** — `MSSQL` tolera mas não recomenda, `Firebird/dbf/SQLite` não permitem `DDL` em transação. `AutoTransaction=false` agnóstico; usuário controla `BEGIN/COMMIT` no `.sql` se `PG` quiser. Tentativa lança `NotSupportedException` descritivo.

[source,csharp]
----
// Won't — throws NotSupportedException (agnostic DDL not supported)
var runnerTx = new MigrationRunner(journal, scripts, factory, new MigrationOptions{ UseTransaction = true });
// throw NotSupportedException("DDL transactions are not supported. Use BEGIN/COMMIT inside the .sql script if your database supports transactional DDL.")
----
