= SqlBatch
include::partial$_attributes.adoc[]
:icons: font

Insert em batch Dapper-friendly, agnóstico a banco (PostgreSQL, SQL Server, SQLite, Firebird) sem `DataTable/SqlBulkCopy`, chunking automático `500` com auto-ajuste para limite `2100` params.

== API

[source,csharp]
----
using Footing.Framework.Data;

public static class SqlBatch {
  public static (string Sql, DynamicParameters Parameters) BuildBatchInsert<T>(string tableName, IEnumerable<T> items, string? columnsOverride = null);
  public static Task<int> InsertBatchAsync<T>(IDbConnection conn, string tableName, IEnumerable<T> items, IDbTransaction? tx = null, int batchSize = 500, CancellationToken ct = default);
  public static Task<int> InsertBatchAsync<T>(UnitOfWork uow, string tableName, IEnumerable<T> items, int batchSize = 500, CancellationToken ct = default);
  public static void ValidateTableName(string tableName); // ^[A-Za-z_][\w]*(\.[\w]*)*$ — rejeita ; DROP
}
----

== Uso com UnitOfWork (atômico)

[source,csharp]
----
await using var uow = new UnitOfWork(factory);
await uow.BeginAsync();
var inserted = await SqlBatch.InsertBatchAsync(uow, "Users", users, batchSize: 500);
await uow.CommitAsync(); // rollback no DisposeAsync se não commitar
----

== Uso sem transação (autocommit por chunk)

[source,csharp]
----
using var conn = factory.CreateConnection();
var inserted = await SqlBatch.InsertBatchAsync(conn, "Users", users);
// cada chunk é 1 ExecuteAsync — sem transação cruzada
----

== Build apenas SQL (teste sem DB)

[source,csharp]
----
var (sql, parms) = SqlBatch.BuildBatchInsert("Users", users);
// sql: INSERT INTO Users (Name, Age, Email) VALUES (@p0_Name, @p0_Age, @p0_Email), (@p1_Name, @p1_Age, @p1_Email), ...
await conn.ExecuteAsync(sql, parms);

// Filtrar colunas (omitir Id auto-increment)
var (sql2, parms2) = SqlBatch.BuildBatchInsert("Users", users, columnsOverride: "Name,Age,Email");

// Com schema
var (sql3, _) = SqlBatch.BuildBatchInsert("public.Users", users);
----

== Chunking & limite 2100

----
5000 rows × 3 cols → 10 statements (500 cada), ~30-50ms
effective = Math.Min(batchSize, 2100 / colCount) // SQL Server 2100 params
----

== Validação de tabela (fail-fast)

[source,csharp]
----
SqlBatch.BuildBatchInsert("Users; DROP TABLE Users --", users); // throw ArgumentException
SqlBatch.BuildBatchInsert("Users.", users);                      // throw (trailing dot)
SqlBatch.BuildBatchInsert("schema.Users", users);                // ok
----

== Performance

Smoke tests validam `<2000ms` para `10k` renders:

[source,csharp]
----
[Fact] public void SqlTemplate_10k_renders_must_be_under_2s() {
  var tpl = SqlTemplate.Parse("SELECT * FROM Users {WHERE} {IF:Name} AND Name=@Name {END} {ENDWHERE}");
  var sw = Stopwatch.StartNew();
  for(int i=0;i<10_000;i++) tpl.Render(new { Name="eder" });
  Assert.True(sw.ElapsedMilliseconds < 2000);
}
----
