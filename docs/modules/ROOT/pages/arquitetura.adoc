----
flowchart LR
  Controller --> Service["Service"]

== Fluxo DI Walk → Lifecycle → Bus

[source,mermaid]
----
flowchart TD
  Scan["Assembly.GetTypes"] --> Filter["Where Has Injectable Service Repository"]
  Filter --> Lifetime["Map Attribute to Lifetime"]
  Lifetime --> Register["Add ServiceDescriptor"]
  Register --> Listeners["RegisterEventListeners"]
  Register --> Lifecycle["PostConstruct PreDestroy"]
----

*Princípios:* agnóstico a banco (`0 Npgsql/Firebird/OleDb` no `src/`), SPI `IOutboxStore/IIdempotencyStore/IMigrationJournal`, `<3.5K LOC`, fail-fast de estrutura vs fail-safe de dados.

== Auto-configuration (TryAdd)

Como Spring Boot: `AddMigrations`, `AddEventBus`, `AddFootingHealthChecks` registram defaults via `TryAddSingleton`. Se o app registrar `AddSingleton<IMigrationJournal, MeuJournal>` antes ou depois, o custom vence.
