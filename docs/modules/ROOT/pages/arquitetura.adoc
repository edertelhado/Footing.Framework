== Fluxo DI Walk → Lifecycle → Bus

[source,text]
----
  Assembly.GetTypes
        │
        ▼
  ┌─────────────────────────────┐
  │ Where Has Injectable /      │
  │ Service / Repository        │
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ Map Attribute to Lifetime   │
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ Add ServiceDescriptor       │
  └──────┬──────────────┬───────┘
         │              │
         ▼              ▼
  ┌────────────┐  ┌────────────┐
  │ Register   │  │ PostConstruct│
  │ EventListeners│  │ PreDestroy  │
  └────────────┘  └────────────┘
----

*Princípios:* agnóstico a banco, SPI `IOutboxStore/IIdempotencyStore/IMigrationJournal`, `<3.5K LOC`, fail-fast de estrutura vs fail-safe de dados.

== Auto-configuration (TryAdd)

`AddMigrations`, `AddEventBus`, `AddFootingHealthChecks` registram defaults via `TryAddSingleton`. Se o app registrar `AddSingleton<IMigrationJournal, MeuJournal>` antes ou depois, o custom vence.
