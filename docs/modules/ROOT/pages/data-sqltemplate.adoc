= SqlTemplate
include::partial$_attributes.adoc[]
:icons: font
:attribute-missing: skip

Template engine leve para SQL dinâmico com Dapper e sem dependência de um banco específico. Permite adicionar ou remover trechos da consulta em tempo de execução com tags como `{IF}`, `{WHERE}`, `{IN}`, `{CHOOSE}`, `{BETWEEN}`, `{TRIM}`, `{SET}`, `{INCLUDE}`, `{BIND}` e `{IFDEFINED}`. O resultado é sempre separado em SQL + parâmetros, preservando queries legíveis e evitando concatenação de valores na instrução.

== Tags suportadas

[cols="1,3,2",options="header"]
|===
| Tag | Descrição | Exemplo

| `{IF: expr} ... {END}`
| `expr := Param \| Param Operator Operand \| length(Param) Operator Operand \| defined(Param) \| A and B` — `Operator := ==\|!=\|=\|<>\|>\|<\|>=\|<=\|gt\|lt\|gte\|lte\|ge\|le` (case-insensitive). `and` simples: `1× and` 2 fatores fora de `''/""`, short-circuit. `defined(Param)` → `ContainsKey`.
| `{IF:Status == 'ACTIVE'} AND x {END}` · `{IF:Busca != null and length(Busca) > 2}`

| `{IFDEFINED:Param} ... {END}` / `{IFNOTDEFINED:Param} ... {END}`
| `ContainsKey` distingue `missing` (false) vs `null/"" /Y` (true). `defined()` alias dentro `{IF:}`.
| `{IFDEFINED:Ativo} AND c.Ativo IS NULL {END}`

| `{WHERE} ... {ENDWHERE}`
| Só adiciona `WHERE` se algo renderizar, remove `AND/OR` líder via `TrimContent`.
| `{WHERE} {IF:Name} AND u.Name=@Name {END} {ENDWHERE}`

| `{IN:Param} ... {END}`
| `IEnumerable` não-string com ≥1 item não-nulo.
| `{IN:Roles} AND u.Role IN @Roles {END}`

| `{CHOOSE} {WHEN: expr} ... {ENDWHEN} {OTHERWISE} ... {ENDOTHERWISE} {ENDCHOOSE}`
| Primeiro `WHEN` true, senão `OTHERWISE`.
| `{CHOOSE} {WHEN: Status=='ACTIVE'} ... {ENDWHEN} {ENDCHOOSE}`

| `{BETWEEN:Param} ... {END}`
| Sugar flat `hasMin && hasMax` (`ParamMin/ParamMax`).
| `{BETWEEN:CreatedAt} AND x BETWEEN @CreatedAtMin AND @CreatedAtMax {END}`

| `{TRIM prefix="..." prefixOverrides="..." suffix="..." suffixOverrides="..."} ... {ENDTRIM}`
| Remove prefixes/sufixos indesejados. Útil para limpar `WHERE`/`AND`/`OR`.
| `{TRIM prefix="WHERE" prefixOverrides="AND\|OR "} AND x {ENDTRIM}` → `WHERE x`

| `{SET} ... {ENDSET}`
| Açúcar `TRIM prefix="SET" suffixOverrides=","`.
| `{SET} {IF:Name != null} Name=@Name, {END} {ENDSET}`

| `{INCLUDE:Fragment}` / `{SQL:Fragment}`
| DRY — `RegisterFragment("BaseColumns","u.Id, u.Name")` + `SELECT {INCLUDE:BaseColumns}`. `ConcurrentDictionary`, depth 5 guard, miss → literal.
| `SELECT {INCLUDE:BaseColumns} FROM Users`

| `{BIND:Var, value='%' + Param + '%'}`
| Injeta `paramDict["Var"]=concat`. Valida `Var ^[A-Za-z_]\w*$`, rejeita `;--/*`.
| `{BIND:LikePattern, value='%' + Name + '%'}`
|===

== Exemplo — 11 tags em 1 query

[source,sql]
----
-- Sql/Users/Search.sql (EmbeddedResource)
SELECT {INCLUDE:BaseColumns} FROM Users u
{BIND:LikePattern, value='%' + Name + '%'}
{WHERE}
  {IF:Name != null and length(Name) > 2} AND u.Name LIKE @LikePattern {END}
  {IF:Email != null} AND u.Email = @Email {END}
  {IF:Status} AND u.Status = @Status {END}
  {IN:Roles} AND u.RoleId IN @Roles {END}
  {CHOOSE} {WHEN: Age >= 18} AND u.Age >= @Age {ENDWHEN} {OTHERWISE} AND u.Age < 18 {ENDOTHERWISE} {ENDCHOOSE}
  {BETWEEN:CreatedAt} AND u.CreatedAt BETWEEN @CreatedAtMin AND @CreatedAtMax {END}
  {IFDEFINED:Ativo} AND u.Ativo IS NULL {END}
  {IF:defined(Ativo) and Ativo == 'Y'} AND u.Ativo='Y' {END}
{ENDWHERE}
ORDER BY u.Name
----

[source,csharp]
----
SqlTemplate.RegisterFragment("BaseColumns", "u.Id, u.Name, u.Email, u.CreatedAt");
var tpl = SqlTemplateLoader.For<UserRepository>("Sql.Users.Search");
var r = tpl.Render(new {
  Name = "eder", Email = "eder@test.com", Status = "ACTIVE",
  Age = 20, Roles = new[] {1,2,3},
  CreatedAtMin = new DateTime(2024,1,1), CreatedAtMax = new DateTime(2024,12,31),
  Ativo = (string?)null
});
await conn.QueryAsync<User>(r.Sql, r.Parameters);
----

== Fail-fast vs fail-safe

*Fail-fast* (`SqlTemplateParseException : InvalidOperationException`):

[source]
----
{IF:Name} ...          // sem {END} → throw S1
{WHERE} ...            // sem {ENDWHERE} → throw S2
{CHOOSE} ...           // sem {ENDCHOOSE} → throw S3
{WHEN: x} ...          // sem {ENDWHEN} → throw S4
{BETWEEN:CreatedAt} .. // sem {END} → throw S5
{IF:Name               // sem } → throw S6 Unclosed tag
{IFDEFINED:Ativo} ...  // sem {END} → throw
----

Mensagem com `Tag/Expected/Line/Column/Snippet/Suggestion`.

*Fail-safe* (dados resilientes — omitido/false):

[source]
----
{IF:Nmae != null} // typo → ContainsKey false → omitido
{IF:"abc" > 100}  // string vs número → false
{IN:Roles} com Roles="admin" // string não é IEnumerable → omitido
----

== Tri-state null/Y/N

[cols="1,3,1,1,1,1,1",options="header"]
|===
| # | Template | `missing` `new{}` | `null` | `""` | `"Y"` | `"N"`

| T1 traz-todos
| `{WHERE} {IF:Ativo} AND c.Ativo=@Ativo {END} {ENDWHERE}`
| traz todos
| traz todos
| traz todos
| filtra Y
| filtra N
|===

Para `IS NULL` use `IFDEFINED`:

[source,sql]
----
{WHERE}
  {IF:Ativo} AND c.Ativo = @Ativo {END}
  {IF:BuscarNulos == true} AND c.Ativo IS NULL {END}
{ENDWHERE}
----

[source,csharp]
----
tpl.Render(new { Ativo=(string?)null, BuscarNulos=false }); // todos
tpl.Render(new { Ativo=(string?)null, BuscarNulos=true });  // IS NULL
tpl.Render(new { Ativo="Y" });                               // Y
----

== `and` / `length()` / `IFDEFINED`

[source,sql]
----
{IF:Busca != null and Busca != ''} AND x LIKE @Busca {END}  -- 1× and ok
{IF:length(Name) > 18} AND Name=@Name {END}
{IF:defined(Ativo) and Ativo=='Y'} AND Ativo='Y' {END}
{IF:Busca != null and Busca != '' and Extra != null}         -- não suportado → false
{IF:Status == 'A' or Status == 'B'}                           -- não suportado → false
----

Para `or`, `and` com 3+ fatores, `()` e `!`, use blocos aninhados ou sequenciais.
